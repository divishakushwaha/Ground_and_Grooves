# Using real photos

The menu shows an illustration (`.svg`) for each item. To use a real photo instead, save it in this
folder as a **.jpg** with the same name as the illustration. The site picks the photo automatically
and keeps the illustration for any item without one.

Use landscape photos (4:3 works best, about 800 x 600 px). Free, commercially usable sources:
[Unsplash](https://unsplash.com), [Pexels](https://pexels.com), [Pixabay](https://pixabay.com).
Credit the photographer in your README.

## Generate the photos with AI

Paste each prompt into an image generator (ChatGPT, Gemini, Microsoft Designer / Bing Image Creator, Adobe Firefly or Midjourney), download the result, and save it as the file name shown. Use a 4:3 or landscape size. Keep the same style line for every image so the menu looks consistent. Check each image for odd details such as extra handles or warped text before using it.
